# Browser transfer regression gate

The existing long-video end-to-end workflow now inspects the actual parse reply from its real worker. For the 80 MiB media fixture, exactly one matching successful parse must report the original logical size, carry less than 1 MiB of compact bytes, and have a backing ArrayBuffer exactly as large as that view. The last condition catches a regression where a small typed-array view transfers an entire logical-file backing allocation. The existing verdict, read-coverage and clean-copy checks remain. Runs in ordinary computer and phone E2E profiles without another giant test fixture or timing threshold. The probe observes messages without blocking, replacing or mocking parser output. This measures one byte-buffer transfer, not the entire structured-clone message, browser RAM or all internal allocations.
