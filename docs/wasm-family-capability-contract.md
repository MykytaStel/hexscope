# WASM family capability contract

Run `node --test scripts/wasm-family-contract.test.mjs` after generating WASM with `pnpm wasm` or `pnpm build`. CI runs this against actual generated bindings and binaries. The contract checks shared parser exports, raster isolation, positive and negative optional-format dispatch for existing public samples, consistent flattened node array lengths, and retention of the format after releasePresentation. It also exercises the four WAVE container signatures through the audio module. These are deliberately selected non-polyglot fixtures: a format with another recognized signature may legitimately be claimed by a different enabled parser. The test does not prove dead-code elimination, ABI equivalence of every function, or identical privacy findings across all feature combinations. The binary size gate remains separate. No parser implementation or feature changes.
