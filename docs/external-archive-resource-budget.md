# External archive read budget

All external compressed ranges share the existing whole-input limit (128 MiB) as an aggregate reservation limit. Reserve before Blob.slice/arrayBuffer and release after synchronous extraction/selection returns or throws. This limits concurrent requested compressed bytes in the reader, not JS heap, WASM copies, decompressed output or browser-internal Blob storage. A valid range temporarily refused because another read occupies the budget can be retried. The per-entry and underlying parser limits do not change. Invalid nonempty range metadata and short reads fail explicitly; an empty range retains the existing WASM fallback. Cancellation and stale selection checks still run before invoking WASM. Tests simulate large ranges without large allocations.
