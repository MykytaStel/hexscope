# File Map — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A "What it's made of" card and an entropy minimap beside the hex view.

**Architecture:** `crates/hexscope-core/src/map.rs` computes a byte-exact role partition (deepest node with a role wins, gaps are Hidden) and windowed Shannon entropy. The bridge sends the partition with the parse and exposes entropy as a free function the worker calls after parsing. The page draws the card in the file panel and a minimap canvas next to the hex canvas, sharing the hex view's scroll mapping.

Spec: `docs/superpowers/specs/2026-09-24-file-map-design.md`. Constraints as in earlier plans (no panics, no new deps, checks before every commit, exit codes checked).
