# Parse tree budget integrity

The existing node limit returns one error sentinel for every subsequent add. Ordinary post-add relabel, range and value mutations now leave that sentinel unchanged, so the first omitted structure remains identifiable and the incomplete-inspection explanation survives. Normal nodes remain mutable. Whole-tree coordinate remapping still applies to the sentinel as to other nodes. Grafting without a mapping stops after exhaustion, and an already exhausted destination returns the sentinel mapping without traversing the source (root mapping remains zero). Mapping requests still allocate one ID per source node by contract. The node ceiling, parser coverage and ordinary tree order do not change. Tests verify the sentinel, parent links, normal mutation and repeated grafts.
