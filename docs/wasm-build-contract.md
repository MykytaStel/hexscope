# WASM build contract

The five existing browser builds share one manifest (crate, features, compressed budget), used by production builds, isolated named diagnostics, size checks and binary profiling. Production uses the existing target/profile and strips name/producer sections. Diagnostic builds still use their own target and output directory. Both now use locked Cargo resolution. No Cargo feature changes, ABI changes or increased size budgets. Production explicitly uses the workspace target directory, matching the old artifact path rather than accepting a conflicting CARGO_TARGET_DIR. Raster output is explicitly named hexscope_raster, matching its crate name. pnpm build still generates explanations and all five builds sequentially. Check pnpm perf:test, pnpm build, pnpm perf:size --check and pnpm perf:profile.
