How many people use hexscope

Counted without knowing who: no cookies, no ids, no addresses kept. These are all the numbers there are, and only the site's key shows them.

How it counts

  • When a page opens, it sends an empty request to /api/seen/day. The answer tells your browser to keep it until midnight UTC, so your browser does not ask again that day. The same for the month and, once, for “new”.
  • The server adds one to that day's total, plus your country (from the network, by Cloudflare), the site you came from, the page, phone or computer, and the language. Only totals are kept: nothing in the database can tell one person from another.
  • Opening a file sends nothing. With “Do Not Track” or Global Privacy Control turned on, pages send nothing at all.

The code is open: server/count.ts and src/count.ts. More in Your files stay on your device.
