Supported formats

See what Hexscope can open. What it can inspect or change depends on the format.

Photos & images

  • JPEG
  • PNG
  • HEIC / HEIF
  • AVIF
  • WebP
  • GIF

TIFF scans work in Film Lab.

Video

  • MP4
  • QuickTime
  • MOV
  • M4V

Includes MOV and M4V files.

Documents & Office

  • PDF
  • DOCX
  • XLSX
  • PPTX
  • DOC
  • XLS
  • PPT

Older Word, Excel and PowerPoint formats included.

Email, archives & technical files

  • EML
  • Outlook MSG
  • ZIP
  • EPUB
  • APK / JAR
  • WebAssembly

Common file types inside ZIP archives are supported too.
